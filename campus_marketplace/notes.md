# State choice notes

## โจทย์ที่ 1: Search Box
- คำค้นหาควรเป็น Ephemeral State เพราะค่าเริ่มต้นเป็นข้อมูลที่ผู้ใช้พิมพ์ในหน้าจอ Home เพื่อกรองรายการสินค้าให้เห็นเท่านั้น
- หน้าจออื่นในแอปไม่จำเป็นต้องรู้ค่าคำค้นหานี้ จึงไม่ควรใช้ Provider หรือ App State
- ใช้ StatefulWidget + setState ใน HomePage เพื่อให้การพิมพ์และการกรองเกิดขึ้นภายในหน้าเดียว และหลีกเลี่ยงการทำ Provider เพื่อฟีเจอร์เล็ก ๆ ที่มีขอบเขตจำกัด

## โจทย์ที่ 2: ปุ่มล้างรายการโปรดทั้งหมด
- ค่ารายการโปรดเป็น App State เพราะข้อมูลนี้ใช้ร่วมกันกับหน้า Home และ FavoritesPage และต้องอัปเดตพร้อมกัน
- ใช้ context.watch<FavoritesModel>() ใน FavoritesPage เพื่อแสดงรายการสดและ rebuild เมื่อรายการเปลี่ยน
- ใช้ context.read<FavoritesModel>() เมื่อกดปุ่มล้างหรือลบชิ้นเดียว เพราะเป็นการเรียก Action แบบ one-time action ไม่จำเป็นต้อง rebuild แบบต่อเนื่องตลอดเวลา
- การแสดง Dialog ยืนยันก่อนล้างช่วยป้องกันการลบโดย accident และเป็น UX ที่ดี
